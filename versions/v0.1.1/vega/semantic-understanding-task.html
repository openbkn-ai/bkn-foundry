Semantic Understanding Task (0.1.0)

Download OpenAPI specification:

Vega Backend 语义理解异步任务 API。任务可针对单个 Resource 或整个 Catalog 创建； worker 将任务提交给 bkn-agent，并异步写回结果与应用状态。
