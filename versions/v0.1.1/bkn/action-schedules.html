ActionSchedule (0.1.0)

Download OpenAPI specification:

行动调度（Action Schedule）管理。行动调度按 cron 表达式定时触发某个行动类对指定实例的 执行。所有接口在 /api/bkn-backend/v1 外网面下，需 OAuth2 认证；branch 查询参数默认 main。时间戳字段为 Unix 毫秒。

ActionSchedule

创建行动调度

在知识网络 / 分支下创建一个 cron 定时触发的行动调度。需 Content-Type: application/json。

Authorizations:
OAuth2
path Parameters
kn_id
required
string

业务知识网络 ID

query Parameters
branch
string
Default: "main"

分支名称，默认 main

Request Body schema: application/json
required
name
required
string

名称，最长 100

action_type_id
required
string

行动类 ID，须存在于该 KN/branch

cron_expression
required
string

合法的 5 段 cron

_instance_identities
required
Array of objects non-empty

实例标识列表，非空（JSON key 带前导下划线）

dynamic_params
object
status
string
Enum: "active" "inactive"

默认 inactive；为 active 时创建即算下次运行时间

Responses

/api/bkn-backend/v1/knowledge-networks/{kn_id}/action-schedules

按名称模糊匹配，默认空

action_type_id
string

按绑定的行动类过滤，默认空

status
string
Enum: "active" "inactive"

按状态过滤，默认全部

offset
integer <int64>
Default: 0

偏移量，>= 0，默认 0

limit
integer <int64>
Default: 10

每页条数，范围 [1,1000]；-1 表示不分页返回全部

sort
string
Default: "create_time"
Enum: "create_time" "update_time" "next_run_time" "last_run_time" "name"

排序字段

string
