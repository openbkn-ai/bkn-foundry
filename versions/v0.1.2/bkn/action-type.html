校验行动类

仅校验行动类依赖存在性，不写库。校验绑定对象类、影响对象类等依赖是否存在。

响应：HTTP 200 时 valid/detail 同其它 validate 接口；参数与鉴权错误为非 2xx。

内部接口：POST /api/bkn-backend/in/v1/.../action-types/validation；Header 解析访问者，无 OAuth。

path Parameters
kn_id
required
string

业务知识网络ID

query Parameters
branch
string

分支，不填则使用 main 分支

strict_mode
boolean
Default: true

是否严格校验依赖，默认为 true

import_mode
string
Default: "normal"
Enum: "normal" "ignore" "overwrite"

与创建行动类接口一致；用于行动类 ID/名称与落库冲突的校验语义（normal / ignore / overwrite）。

Request Body schema: application/json
required
entries
Array of objects

待校验的行动类列表，结构与创建接口一致
