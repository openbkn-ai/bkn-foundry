BKN Import/Export

BKN 导入导出接口

上传 BKN tar 包并导入

上传 BKN tar 包文件并导入为业务知识网络，tar 包内容格式参考 docs/design/bkn/features/bkn_docs/SPECIFICATION.md

Authorizations:
OAuth2
query Parameters
branch
string
Default: "main"

分支名称，默认为 main

import_mode
string
Default: "normal"
Enum: "normal" "overwrite" "ignore"

导入模式。normal 遇到同名概念报错；overwrite 覆盖同名概念； ignore 跳过同名概念。默认 normal。

strict_mode
boolean
Default: true

是否校验依赖对象存在性，默认 true。为空时回退读取已废弃的 validate_dependency

validate_dependency
boolean
Deprecated
Default: true

[已废弃] 请使用 strict_mode。兼容保留，strict_mode 为空时会读取此参数

required
string

业务域

Request Body schema: multipart/form-data
required
file
string <binary>

BKN tar 包文件

/api/bkn-backend/v1/bkns

列出资源

按资源类型分页列出资源（统一资源平台）。当前支持 resource_type=knowledge_network（知识网络）。

Authorizations:
OAuth2
query Parameters
resource_type
required
string
Value: "knowledge_network"

资源类型。当前实现只识别 knowledge_network（知识网络）， 对应 interfaces.RESOURCE_TYPE_KN。

传其他值不报错，而是走 default 分支返回 200 且响应体为空 （不是空列表，是完全没有 body）。取值写错时的表现是客户端 JSON 解析失败或拿不到任何数据，而不是 400。

keyword
string

名称关键字过滤，默认空

offset
integer <int64>
Default: 0

偏移量，默认 0

limit
integer <int64>
Default: 10

每页条数，默认 10

sort
string
Default: "name"

排序字段，默认 name

direction
string
Default: "desc"
Enum: "asc" "desc"

排序方向，默认 desc
