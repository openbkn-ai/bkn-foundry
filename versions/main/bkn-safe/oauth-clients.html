身份与授权 · MCP 客户端登录与已连接客户端 API (0.1.0)

Download OpenAPI specification:

Lets MCP clients such as WorkBuddy, Claude Code and Cursor sign a user in with only the Context Loader MCP URL: the client reads the protected-resource metadata (RFC 9728) and the authorization-server metadata (RFC 8414), registers itself (RFC 7591) and opens Hydra's authorize endpoint in the browser. Hydra's own dynamic registration stays disabled; bkn-safe admits only public clients that must sign a user in (authorization_code + PKCE, refresh allowed, no client_credentials) with loopback callbacks, and creates them through Hydra's admin API.

Users list and disconnect the clients they connected; administrators list and remove any self-registered client. First-party clients (Studio, CLI) are never listed or touched.

The discovery and registration routes exist only when config.oauth.dynamicRegistration.enabled is true.

Register an MCP client (RFC 7591)

Unauthenticated by design: a client registers before anyone has signed in. Requests are rate-limited per client IP. Whatever grant types the client asks for, the created client gets authorization_code and refresh_token and the scope openid offline offline_access.

Request Body schema: application/json
required
redirect_uris
required
Array of strings <uri> non-empty [ items <uri > ]

Loopback callbacks (http://127.0.0.1:*, http://localhost:*, http://[::1]:*) or an origin listed in config.oauth.dynamicRegistration.allowedRedirectOrigins.

client_name
string <= 64 characters
grant_types
Array of strings
Items Enum: "authorization_code" "refresh_token"
response_types
Array of strings
Items Value: "code"

string
