Chat Completions

OpenAI-compatible chat completion. stream=true returns an SSE stream; otherwise the upstream completion is returned as JSON. Public calls require large_model:execute permission. Request validation errors use the OpenAI error envelope. Provider 401/403/404 errors normalize to HTTP 502; retry exhaustion can return HTTP 503. Streaming failures appear in SSE error frames.
