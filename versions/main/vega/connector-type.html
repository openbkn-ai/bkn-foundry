ConnectorType (0.1.0)

Download OpenAPI specification:

APIs for Vega Backend connector types.

A connector type describes a registered data-source driver, such as mysql, postgresql, or opensearch, together with its registration metadata and enabled state. Field configuration (field_config, compatible with JSON Schema properties) is returned only by the detail endpoint and is obtained from the runtime implementation. Local definitions come from implementations in the current process; runtime field definitions for remote connectors are not yet implemented. mode distinguishes in-process local connectors from remote connectors invoked over HTTP. category identifies the data-source category.

List connector types

Returns paginated summaries of registered connector types without field_config. Supports filtering by name, tag, mode, category, enabled, and available.

Update a connector type

Fully updates the connector type identified by the type path parameter. The primary key cannot be changed.

The request body must include type, and it must exactly match the path parameter:

  • Missing → 400 VegaBackend.ConnectorType.InvalidParameter.Type.
  • Mismatch → 409 VegaBackend.ConnectorType.TypeMismatch.

If a new name is already used by another type, the endpoint returns 409 VegaBackend.ConnectorType.NameExists.
