Vega Backend Resource 数据子资源（/resources/{id}/data）相关 API。

large_integer 字段通过十进制字符串无损传输。Doris 源端比较、range、out_range、between、 分组、排序和 MIN/MAX 使用数值语义；SUM/AVG 暂不支持。 托管本地索引将其作为 string/keyword 存储和查询，复用既有字符串操作规则， 不支持 large_integer 数值范围或聚合语义；例如 "0100" 不匹配存储文本 "100"。 Dataset 不允许声明 large_integer 字段。 输入推荐使用整数字符串（可含正负号及前导零）；非法及越界常量遵循源端 CAST 设置。 区间不重排边界，range/between 为闭区间，out_range 为两端严格外部区间；NULL 边界拒绝。

本规范覆盖两类语义：

  1. 通用资源数据查询：POST /resources/{id}/data + X-HTTP-Method-Override: GET， 对任意 category 的 Resource 执行数据查询（filter + 分页）。
  2. dataset documents 的写/删/访问：POST 的 Override: POST 创建一条文档， PUT 完整替换一条文档，GET / DELETE 支持按逗号分隔的文档 ID 批量操作； 它们以及 POST 的 Override: DELETE 分支，仅对 Resource.category=dataset 生效。

dataset 不顶层化：dataset 在系统中只是 Resource.category=dataset 的特化形态， 无独立 ID 体系。CRUD 走 /resources/{id}，仅 documents 子资源（即本规范）独立 API surface。

端点设计遵循 [vega-backend/CLAUDE.md] 的"端点设计规则"。POST /data 用 X-HTTP-Method-Override 头多分发，是为了兼容现有 query 语义并在同一条路径上 暴露 create / delete-by-filter，避免在仓库内引入新的"动作端点"形态。

错误码复用 Resource 系列：本规范不引入 Dataset.* 专属错误码；单条文档不存在 与 resource 不存在共用 VegaBackend.Resource.NotFound，靠 error_details 区分。

cursor 可通过 DELETE /resources/cursors/{cursor} 提前关闭，详见 raw-query.yaml。默认空闲租约为 1800 秒；单账号 cursor session 默认上限 100，全局默认上限 1000。

Resource 数据多分发端点

必须带 X-HTTP-Method-Override 头，值是 GET / POST / DELETE 之一 （大小写不敏感）；缺失或值非法返回 400 VegaBackend.InvalidParameter.OverrideMethod。

三种分支：

Override 行为 category 限制 body schema
GET 列表 / 查询文档 任意（兼容现有通用查询） ResourceDataQueryParams
POST 创建一条文档 dataset 强制 Document（不得传 _id，由后端生成）
DELETE 按 filter 删除文档 dataset 强制 ResourceDataQueryParams（filter_condition 必填非空）

Override: GET 响应：200 + { entries, total_count, paging }。cursor 模式通过 paging.next_cursor 续页；total_count 仅在 need_total=true 时返回。 逻辑视图查询要求 EE 专业版及以上授权；未安装 EE 扩展返回 501， 授权版本不足返回 403 Public.Forbidden。 HANA 源表无 SELECT 权限时返回 403 VegaBackend.Resource.SourceReadForbidden，不暴露驱动原始错误。 已保存的衍生逻辑视图因源字段删除、绑定/类型不匹配、输出 Feature 变化， 或固定过滤条件非法（包括缺值、非法范围、不支持的算子）、无法按当前 schema/index 配置构造时， 返回 400 VegaBackend.LogicalView.DefinitionInvalid。 description 包含可识别的相关字段及编辑视图的修复提示；error_details 包含 fields（源字段名数组；输出绑定使用 original_name，过滤条件使用 field 名称）及 reason （source_field_mismatch、source_feature_mismatch、filter_field_missing 或 filter_incompatible）。 普通查询条件非法仍返回 400 查询参数错误；不因条件来自已保存定义而改为 500。 本地索引精确查询值超过 keyword ignore_above 时，返回 HTTP 400 VegaBackend.Resource.QueryValueExceedsKeywordLimit。metadata.field 为请求字段名， metadata.limit 为正整数长度上限，单位为 UTF-16 code units。 客户端按 error_code 判断错误类型，使用 metadata 生成本地化提示，不解析 error_details。 此错误不会自动回源或降级为空结果；调用方可缩短值，或主动设置 ignore_local_index=true （仅支持源查询的资源）。旧版后端的通用 InvalidParameter 错误仍按通用错误处理。 非过滤条件的视图存储结构损坏、源读取及模型服务故障仍按原有错误处理。 已保存的复合逻辑视图在首次查询和 cursor 续页时也暂时返回 501。

Override: POST 响应：201 + { id }。后端生成文档 ID；携带 _id 的 body 返回 400。

Override: DELETE 响应：204。空 filter_condition 拒绝 400 避免误删全表。

非 dataset category 的 resource 调 Override=POST/DELETE → 400 VegaBackend.Resource.InternalError.InvalidCategory。

过滤条件，结构由 FilterCondCfg 决定。Override=DELETE 时必填且非空。 knn_vector 在索引维度已知时校验向量长度：调用方原始向量维度不匹配返回 HTTP 400 VegaBackend.Resource.InvalidParameter，error_details 包含实际及要求维度； 模型输出维度不匹配返回服务端错误。匹配维度的原始向量和文本检索仍受支持。 旧索引缺少维度元数据时维持原查询行为，下游维度错误仍返回 HTTP 500。 模型服务、索引或其他基础设施故障保持服务端错误分类。 比较、集合与范围条件的时间常量统一采用以下输入契约（timestamp 兼容类型沿用既有行为）：

  • datetime 支持 RFC3339（如 2026-10-19T00:00:00+08:00）、 无时区完整时间 YYYY-MM-DD HH:mm:ss[.fraction]、整数毫秒时间戳。 毫秒时间戳同时接受 JSON 整数和十进制数字字符串，拒绝小数及 int64 溢出； datetime 不接受仅日期字符串。字符串小数秒支持 1–9 位；超过 9 位返回 HTTP 400，不静默截断。
  • date 只接受 YYYY-MM-DD，不接受 RFC3339、完整时间或时间戳；保留日历日期。
  • time 只接受 HH:mm:ss[.fraction]，小时为 00–23，小数秒支持 1–9 位；超过 9 位返回 HTTP 400； 不接受日期、时区或时间戳，保留一天中的时间。 datetime 的无时区字符串按服务器 TZ 解释，TZ 未配置或为空白时使用 UTC； 带时区字符串及毫秒时间戳表示绝对时刻，无时区源列按服务时区的墙上时间比较。 时间字符串和服务内部游标均保留最多 9 位小数秒；数字时间戳始终按整数毫秒解释。 保留原始时间值，运行时使用解析后的条件副本；因此无时区字符串会按当前服务器 TZ 解释。 非法值返回 HTTP 400，服务器 TZ 配置错误返回 HTTP 500。 这些规则同样适用于派生视图固定条件；创建和更新拒绝非法定义， 已有非法固定条件返回 VegaBackend.LogicalView.DefinitionInvalid。 源连接器的字段能力和类型范围仍然生效，不支持的源类型不能仅凭格式合法而执行查询。 OpenSearch datetime 集合按绝对时刻去重后展开为精确范围，每个集合最多允许 1024 个不同时刻； 含 datetime 范围的整棵过滤条件最多允许 1024 个查询子句，超限返回 HTTP 400。 该限制同样适用于整毫秒值、in 和 not_in，与字段 mapping 的日期格式无关。 time 输入去掉小数秒尾部零后比较，等价的 12:00:00.1 与 12:00:00.100 查询结果一致。 上述格式要求适用于过滤输入，不作为源端数据写入的接受集。 本地索引构建按源值保留 DATE 的日历日期，不把服务时区零点当作 UTC 时刻存储； CDC 的 DATE 天数及 TIME 毫秒/微秒/纳秒仅按消息 schema 的逻辑类型解码。 有符号或超 24 小时 TIME 时长及未知源表示保留原值，不因不符合日内时间输入格式中断构建； 这不扩展公开 time 过滤输入为时长。time 集合使用 keyword terms， 去重并展开等价尾零形式后最多允许 65536 项，超限返回 HTTP 400；仍受引擎自身配置限制。 过滤时间常量时兼容旧索引中的合法 HH:mm:ss[.fraction] 尾零形式； 旧索引若将原生 time 写成完整日期时间字符串，需重新构建以恢复日内时间语义； 原生 DATE 曾按带时区零点写入的旧索引也需重建以保证日历日期过滤一致。

output_fields
Array of strings

指定输出字段列表。显式指定的字段必须全部合法；任一字段不存在时整单拒绝，返回 HTTP 400 VegaBackend.Query.InvalidParameter.OutputField，不静默删除字段。 字段存在但当前查询通道不支持读取时返回 HTTP 400 VegaBackend.Query.UnsupportedOutputField；默认投影没有可查询字段时返回 HTTP 400 VegaBackend.Query.NoQueryableFields。真实源连接、执行故障不归入这些错误。 省略或传空列表使用默认投影。本地索引通道对 Binary/Other 字段保留 unavailable 展示语义，显式请求与默认投影一致；该占位表示索引中无法读取原值。 聚合查询只能指定分组字段和实际聚合结果别名（未指定 alias 时为 __value）； 其他源字段不能作为聚合输出。显式选择仅裁剪结果列，不改变分组、排序、分页、行数或 total。 派生逻辑视图的非聚合查询可指定 _score；索引通道返回真实 相关性分数，source 表查询不返回该元字段，不补零或伪造分数。

完整替换一个 dataset 文档（upsert）

docid 是目标文档 ID。body 中的 _id 会被路径参数覆盖；文档已存在时完整替换， 不存在时以该 ID 创建，不支持 patch/merge 更新。

对 string / text 字段上的 vector Feature：若 body 显式携带派生字段 <field>_vector，服务端校验后直接使用；否则源文本非空时同步生成向量。生成或 校验失败时不会向 OpenSearch 写入该文档。

category 限制：仅 dataset。

按 ID 删除一个或多个 dataset 文档

默认严格：服务端在删除前核验全部文档，任一不存在即返回 404，且不发起删除。 ?ignore_missing=true 时跳过不存在的文档，仅删除已找到的文档。

这是一请求内的预检语义；预检后发生的并发删除仍可能使底层批量删除失败。 category 限制：仅 dataset。
