Query an immutable published object metric version.

Authorizations:
bearerAuth
path Parameters
kn_id
required
string
metric_id
required
string
query Parameters
branch
string
Default: "main"
version
required
integer >= 1

Immutable published metric version. Runtime never resolves an implicit latest version.

Request Body schema: application/json
required
Array of objects
(ObjectMetricScalarPredicate (object) or ObjectMetricMembershipPredicate (object) or ObjectMetricRangePredicate (object) or ObjectMetricUnaryPredicate (object)) or object or object (ObjectMetricCondition)
Array of objects (PropertyRef)

Runtime dimensions selected from the metric definition's query_capabilities.analysis_dimensions. Fixed grain is always applied and cannot be removed.

object

Filters final metric values after the complete atomic, derived, or composite result is computed. Rejected on partial results.

Array of objects

Sorts final rows. Ties are broken by the stable result identity; nulls sort last.

page_size
integer [ 1 .. 1000 ]

Optional. Omit to return all rows; pagination is stateless and re-evaluates the query.

cursor
string

Opaque next_cursor from a prior page of the identical query. Returns 409 if the recalculated result has changed.

object
object

Responses

/api/ontology-query/v1/knowledge-networks/{kn_id}/object-metrics/{metric_id}/data
