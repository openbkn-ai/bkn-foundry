BKN 知识网络 · 值类型 API (0.1.0)

Download OpenAPI specification:

Value types of a knowledge network (BKN specification 3.0, section 16). A value type is a base type with a set of value rules (an enum, or a range, a length, a pattern and a unit), named so that several data properties can share it: a property names one in constraints.value_type.

Value types have no authorization of their own. Reads and lists need view_detail on the knowledge network; creating, updating and deleting need modify on it. See ../knowledge-network-authorization.md.

The rules are checked with the checks a BKN 3.0 import runs: base_type is one of the listed types, an enum goes with none of range, length and pattern, enum values fit the base type and do not repeat. A data property that names a value type must have the value type's base_type as its Type, and writes no range, length, pattern or unit of its own.

While a data property names a value type, the value type cannot be deleted, and an update must keep a base_type the referencing properties fit. Either refusal is 409 BknBackend.ValueType.Referenced, and its details list the referencing object types and properties.

All APIs are exposed under /api/bkn-backend/v1, require OAuth2 authentication, and default the branch query parameter to main. Writes are recorded in the operation audit.
