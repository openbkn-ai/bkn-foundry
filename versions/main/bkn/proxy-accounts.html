BKN Knowledge Network Managed Proxy API (0.2.0)

Download OpenAPI specification:

OAuth-protected governance APIs and cluster-internal runtime APIs for environment-local knowledge-network proxy mappings.

The model version covers data and execution bindings only. A Skill mounted on the network contributes a skill/execute grant source that resolve accepts and synchronization materializes, but it is excluded from the version and is best effort: when the delegator lacks execute on the Skill, or bkn-safe rejects Skill sources, synchronization leaves that grant out, logs it, and the mapping still becomes ready. Mounting a new Skill still requires the mounter to hold execute on it, as for a tool.

List knowledge-network proxy mappings in the caller's governance scope

Returns only mappings for knowledge networks on which the OAuth caller has the authorize operation. Unauthorized mapping existence and proxy account identifiers are not disclosed.
