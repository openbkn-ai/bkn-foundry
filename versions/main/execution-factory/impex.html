导入导出 (0.1.3)

Download OpenAPI specification:

把算子、工具箱、MCP 打成 .adp 包导出，或从包导入回来。用于环境间搬运与备份。

导出是 GET、导入是 multipart：导入不是发 JSON，而是把 .adp 文件作为 表单字段 data 上传，Content-Type 必须是 multipart/form-data， 否则直接 415。

认证：Authorization: Bearer <token>（OAuth access token 或 bak_ 前缀的 AppKey）。

Impex

导出组件配置

导出单个组件的配置。响应带 Content-Disposition: attachment; filename=<type>_export_<时间戳>.adp， 浏览器会直接落盘；Content-Type 仍是 application/json——.adp 就是 JSON。

导出内容按 type 落在响应的对应字段里（operator / toolbox / mcp）， 其余字段不出现。

导入组件配置

上传 .adp 包导入组件。

三个容易踩的点：

  1. **必须 multipart/form-data**。发 JSON 会直接 415，报文写明 Content-Type must be multipart/form-data。
  2. **文件字段名固定是 data**，不是 file。 mode 决定同名组件的处理：create 只新建，撞上已存在的就报错； upsert 存在则更新。默认 create。
