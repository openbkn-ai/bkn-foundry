Agent Observability API (1.0)

Download OpenAPI specification:

Community Core APIs for managed Conversation/Interaction facts, recorded Operations, and technical Trace reads. Standard record authorization applies. Enterprise business-provenance routes require an assembled EE image and runtime enterprise entitlement; they are not part of this Core specification. A plain 404 on an enterprise route does not identify its cause: an absent Community route, the EE availability gate, or an undisclosed record can return 404. A successful Core read does not establish access to an EE route. Explanation reads are separate from explicit EE generation requests. See the module README for the Community/EE read boundary.
