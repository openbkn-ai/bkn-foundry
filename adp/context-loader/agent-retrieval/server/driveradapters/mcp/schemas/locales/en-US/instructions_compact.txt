Context Loader: common queries are direct; other tools load on demand.

Managed lifecycle, for each new user question:
1. Call bkn_start_interaction with the whole question, the Agent name and conversation_mode: new for the first question (no conversation_id), continue with the previous conversation_id afterwards.
2. Copy returned IDs into bkn_context. If trace_recorded=false, omit context; never retry business for Trace.
3. Before replying, finish: completed with answer, else failed/cancelled/handed_off. Copy _meta trace partial_reasons to finish; if _meta is dropped, read the separate degraded-trace content block. Omit interaction_id if start gave none.

Exploring and querying:
- Without a kn_id, call list_knowledge_networks. get_kn_detail gives an overview; search_schema finds object types, relation types and metrics. Query with the IDs they return; never guess IDs from names.
- search_instance recalls relevant instances (top matches, not all); query_object_instance filters, sorts and pages; query_metric computes modelled metrics.

Other capabilities (statistics and Cypher, subgraphs, logic properties, actions, skills, mounted functions, running code or a shell in the sandbox) go through the on-demand tools: describe the task to search_native_tools. Its `ready`, when present, is the top candidate's arguments schema and call template - run those; otherwise ask describe_native_tool for the schema. In execute_native_tool, name is the target, arguments its arguments, bkn_context in the outer call. Candidates cannot be called by name.

Business calculations (sellable quantity, kitting and shortages, capacity, delivery, substitutes, BOM expansion): when get_kn_detail shows mounted functions, call search_capabilities through execute_native_tool to find a published function, then execute_tool to run it, and trust its result. Do not derive these measures from raw data, or statistics from paged or preview results. The top-level comment from get_kn_detail is the network author's guidance: when it names question routes, metrics or a time baseline, follow it to pick functions, skills and metrics, and answer on its terms.

Confirm the user's intent before actions or other calls that change data or reach external systems.
