# BKN Foundry 0.2.2

[English](0.2.2.md) | 中文

## BKN 项目：知识库属于专业版功能

从 0.2.2 起，基于文档构建 BKN 项目属于**专业版**（openbkn-ee）功能：选择知识库来源、
从文档抽取概念、构建和验收文档实例、随发布一起发布以及刷新。开源社区版保留基于结构化
数据的建模（从数据表起草、候选、判定、场景、发布、切换和回退），以及专业版使用的扩展点。
社区版里知识库入口仍然隐藏，相关接口仍返回 404。

专业版在服务启动前运行 `bkn-project-ee migrate`，创建自己的表和 Agent。

## BKN 项目不支持从 0.2.1 升级

知识库和 BKN 项目在 0.2.1 是测试版。0.2.2 全新安装这两部分，不提供从 0.2.1 的升级或数据迁移。
在 0.2.1 用过 BKN 项目的安装，升级前需要手动清理（先备份；社区版和专业版步骤相同）：

1. 把 `bkn-project` 缩到 0 副本，删除它的全部 `t_bkn_project_*` 表。
2. 执行 `DELETE FROM deploy.t_schema_migration_task WHERE f_service_name='bkn-project'`。
3. 删除存储卷 `bkn-project-git`（或清空 `/data/git`）。
4. 从 `t_agent`、`t_agent_version`、`t_agent_prompt`、`t_agent_prompt_version` 删除
   `bkn-project-concept-extraction`、`bkn-project-document-extraction` 两个 Agent 及其提示词；
   不要动 bkn-agent 的迁移记录和其他 Agent。
5. 升级。表结构按全新安装创建，专业版随后运行自己的迁移。

0.2.1 项目在 bkn-backend 发布的网络、抽取出的 Dataset 和知识库保留登记不会被删除，
不再需要的由管理员清理。
